All you need to know about TTP223 Capaciitive Touch Sensor

In this article, I’m going to discuss about TTP223 Capacitive Touch Sensor module. A capacitive touch sensor detect touch by measuring variation in capacitance when a conductive object is brought closer to the sensor. Genrerally, in a capacitive touch sensor, copper pad on PCB act as bottom conductive plate, PCB material along with air act as dielectric and our finger act as the second plate. Therefore a capacitance is formed when our finger is brought closer to the copper pad. TTP223 will detect this change in capacitance and provide a usable output. TTP223 can be configured for Active HIGH or Active LOW output. In both modes it suports both momentary and self latching output. However, every TTP223 module may not provide us the choice to configure.

UART: Universal Asynchronous Receiver and Transmitter

UART is a two wired Asynchronous serial communication protocol For UART Communication, we need to configure both devices with same speeed, i.e. baud rate. Baud Rate is the data transfer rate on bits per sec. UART Protocol requires a start bit and a stop bit. Data length can vary froom 5 bits to 9 bits. These should be configured before using UART. It uses NRZ (Non Return to zero) encoding for transmission. UART uses little endian bit ordering, which means the least significant bit is transmitted first.
